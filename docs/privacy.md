# Privacy and Security Policy

## Core Principles

1. **Zero Content Storage**: The system never logs or stores actual characters typed, keystroke letters, or text input.
2. **Key Anonymization**: Individual physical keys are hashed with a local salt into non-reversible identifiers or grouped into generic categories (e.g., `KEY_DELETE`, `KEY_ENTER`, `KEY_MODIFIER`).
3. **Local Processing**: Feature extraction, model inference, and score fusion are performed 100% on-device. No behavioral data or telemetry is transmitted across the network.
4. **Transparent User Control**: Users can inspect collected features, delete enrollment profiles, and adjust sensitivity parameters at any time.
